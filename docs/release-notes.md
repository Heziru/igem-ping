# A little company for every iGEMer

The community edition of iGEM Ping brings Gemy and official iGEM navigation to the Windows desktop.

- The default **iGEM Guide** wheel opens six official shortcuts in order: **Timeline**, **Judge handbook**, **Submission guides**, **Past teams**, **Start here**, and **My deliverables**.
- Draggable transparent companion, with a separate **Signals** mode for six animated local pings.
- `Ctrl + Alt + G` opens the wheel; `1–6` selects an item in the current mode and `Esc` closes it.
- `Ctrl + Alt + P` shows or hides Gemy. Right-click Gemy for preferences.
- A 1–180 minute focus timer, gentle sound, reduced motion, and three companion sizes.
- English and Simplified Chinese.
- A complete iOS-inspired ImageGen PNG skin for icons, backgrounds, panels, and buttons. Labels remain real text, and controls retain accessible names and keyboard interaction.
- Official resources include Wiki editing, asset uploads, Video Universe, the all-years team directory, and Phoenix project search, which covers projects through 2022 only.
- No app account, background network requests, or telemetry.

**Submission guides** opens the [public deliverable guides](https://competition.igem.org/deliverables/guides). The resource page separately links to [Wiki getting started](https://teams.igem.org/go/deliverables/wiki/getting-started) and [Wiki Uploads](https://teams.igem.org/go/deliverables/wiki/uploads), which require an iGEM login and team selection. **My deliverables** opens the [team deliverables dashboard](https://teams.igem.org/go/deliverables), where you can check submission status and deadlines after signing in and selecting your team. Uploading an asset does not submit a competition deliverable.

**Timeline** opens [competition deliverables and deadlines](https://competition.igem.org/deliverables/); **Judge handbook** opens the [official judging handbook](https://competition.igem.org/judging/handbook). **Past teams** opens the [all-years team directory](https://teams.igem.org/list?year=all); **Start here** opens the [official starter guide](https://competition.igem.org/about/starting-a-team). The wheel opens live official pages in your browser. The app does not read login sessions or synchronize team submission status.

Download the Windows x64 portable `.exe` below. No installation is required. The build is unsigned; Windows may show a publisher notice. macOS and Linux packages are not yet provided.

Pings appear on your computer; they are visible in a whole-screen share. This release does not include online rooms or teammate-to-teammate messages. A running focus session ends when the app quits.

This is an independent community project, not an official iGEM application. Code is MIT licensed; Gemy and iGEM identity are excluded. See `ASSETS.md` for official sources and artwork terms.

让 Gemy 陪伴每一位 iGEMer，也让官方入口更容易找到。默认的 **iGEM 新手导航**轮盘依次提供：**赛程与截止、评审手册、上传与提交指南、历届队伍项目、新手入门、我的提交进度**。切换至**协作信号**模式，可使用六种本地桌面信号；同时支持可拖动桌宠、专注计时和中英双语。

图标、背景、面板和按钮采用整套 ImageGen 生成的 iOS 风格 PNG 皮肤；文字仍为真实文本，交互保留可访问名称与键盘支持。

“评审手册”直接打开[官方评审手册](https://competition.igem.org/judging/handbook)。“上传与提交指南”打开[公开提交指南](https://competition.igem.org/deliverables/guides)。资源页另有需要登录并选择队伍的 [Wiki 编辑入门](https://teams.igem.org/go/deliverables/wiki/getting-started)、[Wiki 素材上传](https://teams.igem.org/go/deliverables/wiki/uploads)，以及 [Video Universe](https://video.igem.org/)、[全年份队伍目录](https://teams.igem.org/list?year=all)和仅收录至 2022 年的 [Phoenix 项目搜索](https://community.igem.org/projects/phoenix-project)。“我的提交进度”进入[团队提交面板](https://teams.igem.org/go/deliverables)，登录并选择队伍后，可查看提交状态和截止事项。上传素材不等于完成正式提交。

应用本身无需账号；所有导航均在浏览器中打开实时官方页面，不读取登录会话、不同步后台提交状态。“赛程与截止”打开公开的官方要求和日期；“我的提交进度”打开需要登录的团队状态页面。

下载下方 Windows x64 便携版即可运行。`Ctrl + Alt + G` 打开轮盘，`1–6` 选择当前模式的项目，`Esc` 关闭；`Ctrl + Alt + P` 显示或隐藏桌宠，右键桌宠进入设置。此版本仅在本地显示 Ping，可通过全屏共享让伙伴看见；不含联网房间。退出应用会结束当前计时。
