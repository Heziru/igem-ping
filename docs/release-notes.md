# A little company for every iGEMer

The first community edition of iGEM Ping brings Gemy to the Windows desktop.

- Draggable transparent companion, with six animated local pings.
- `Ctrl + Alt + G` opens the wheel; `1–6` selects a ping and `Esc` closes it.
- `Ctrl + Alt + P` shows or hides Gemy. Right-click Gemy for preferences.
- A 1–180 minute focus timer, gentle sound, reduced motion, and three companion sizes.
- English and Simplified Chinese.
- Official competition, deliverables, Registry, engineering, safety, community, and Jamboree links.
- No account, background network requests, or telemetry.

Download the Windows x64 portable `.exe` below. No installation is required. The build is unsigned; Windows may show a publisher notice. macOS and Linux packages are not yet provided.

Pings appear on your computer; they are visible in a whole-screen share. This release does not include online rooms or teammate-to-teammate messages. A running focus session ends when the app quits.

This is an independent community project, not an official iGEM application. Code is MIT licensed; Gemy and iGEM identity are excluded. See `ASSETS.md` for official sources and artwork terms.
