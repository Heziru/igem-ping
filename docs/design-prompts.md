# Interface skin prompts

Tool: built-in OpenAI ImageGen. Both accepted images used `transparent_background: true`. Originals were copied unchanged into the repository; CSS selects their usable raster regions for nine-slice display.

## `assets/ios-button.png`

> Use case: ui-mockup. Asset type: production UI button skin PNG for nine-slice stretching in an iOS-inspired desktop app. Generate ONE blank blue rounded SQUARE on a genuinely transparent canvas, straight front view, centered, square edges parallel to canvas. The shape occupies 94% of canvas width and height, with small corner radius exactly about 8% of shape width. Style: contemporary iOS restrained sapphire blue, flat luminous surface, exceptionally subtle top light, no raised bevel, no thick outlines, no glow, absolutely no cast shadow. Solid fully opaque blue inside, including the center. Perfect clean antialiased perimeter, zero noisy alpha pixels or stray specks. Outside shape must be completely transparent. All curved portions MUST be confined to the outer 15% of the canvas, leaving very long perfectly straight sides for clean nine-slice use. No text, icons, symbols, inner shapes, metallic edges, reflections, glass streaks, ornamentation, watermark, or multiple objects. This is a finished UI source skin, not a mockup displayed in a device. Calm premium current iOS visual design; avoid glossy 2000s skeuomorphic styling.

## `assets/ios-panel.png`

> Use case: ui-mockup. Asset type: production nine-slice UI panel skin. Generate ONE blank perfectly front-facing rounded SQUARE in pale opaque ice-white, centered on a genuinely transparent square canvas. Shape takes 96% canvas width and height. Corner radius small, exactly 7% of shape width. Contemporary iOS restrained card surface: very pale cool white, an almost imperceptible fine pale blue rim INSIDE the perimeter, subtle gentle internal luminosity, no protruding bevel, no metallic glass tubing, no cast shadow, no halo, no exterior glow whatsoever. Fully solid opaque white interior suitable behind dark text. Perimeter must be perfectly clean antialiased pixels. Outside shape entirely transparent with absolutely no specks, dithering, patches or cloudy remnants. All curvature contained in outer 12% of canvas; straight long sides for nine-slice scaling. No text, glyphs, icons, logos, device mockup, additional objects or perspective. The entire outside transparent field must be immaculate. Current iOS understated premium UI, not shiny 2000s skeuomorphic plastic.

The generated PNGs contain some stray pixels outside their shape bounds despite the prompt. The renderer excludes that outer margin with CSS image viewports; it does not synthesize replacement artwork or modify the bitmap. Source rectangles are documented in `src/shared.css`.
